Base stat changes

Origin HeartGold changes the base stats of many Pokémon: some get a higher base stat total (BST), others keep the total but move points between stats. The tables list the 340 species and forms you can get in the game whose base stats differ from the official games. This is how the original Chinese hack works; the English patch changes none of it.

“Official” is the species’ latest official base stats, so changes made in later official games (for example Pikachu’s higher Defense) don’t count as Origin HeartGold changes. The Pokémon pages always show the stats you will actually meet. See also Type changes.
