Thief

Effect

The user attacks and steals the foe’s held item simultaneously. It can’t steal if the user holds an item.

Move stats
TypeCategoryPowerAccuracyPPPriorityTarget
DarkPhysical60100250Selected target

Changes in Origin HeartGold

Compared with Pokémon HeartGold.

  • Power: 40 → 60.
  • PP: 10 → 25.

Pokémon that learn this move

510 Pokémon and forms can learn this move. Check availability before planning your team.
