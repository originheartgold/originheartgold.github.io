Psych Up

Effect

The user hypnotizes itself into copying any stat change made by the foe.

Move stats
TypeCategoryPowerAccuracyPPPriorityTarget
NormalStatus——100Selected target

“—” power marks a status move. “—” accuracy means no accuracy check.

Changes in Origin HeartGold

No changes listed.
